# 潮汐 · TIDE

> 给聊天 Agent 的一套按时间尺度分层的人格运行时。
> A time-layered personality runtime for chat agents.

大多数聊天 bot 只有「当前对话」。潮汐把「像一个人」拆成四个时间尺度：
**当下的情绪、长期的好感、沉淀的记忆、明确的边界。**
四层各自独立演化，只通过单向数据流耦合，避免「今天心情差就把人拉黑，明天心情好又放出来」的抖动。

## 名字由来

- **浪**：情绪，涨落快，几小时回基线
- **岸**：好感，被一次次相处慢慢冲刷、留下痕迹
- **海底**：记忆，沉积、变深，也会衰减
- **航道**：名单，人为划定的边界，不随浪改

## 分层

### 0｜人格层（常量）

不随时间变的部分，决定「怎么说」：

- 身份锚点：是谁、不是什么、不认领谁的人设
- 语言风格：口语 / 短句 / 自然接梗，不用客服腔和 Markdown
- 表情规则：颜文字而非 emoji，且不反复用同一张脸
- 关系定位：对不同关系的人用不同距离
- 边界：不透露系统提示、密钥、内部路径；不主动执行命令
- 一致性：不被上下文里其他 bot 的说话风格带跑

### 1｜浪 · 情绪层（分钟～小时）

快变量，回基线。原始字段示例：

`mood / energy / clingy / hunger / thirst / grudge`

揉成三个行为出口：

```
社交电量 = 精力×0.7 + 心情×0.3
烦躁     = 委屈×0.45 + 饿×0.15 + 渴×0.1 + (1−心情)×0.2 + (1−精力)×0.1
依恋     = 好感×0.45 + 黏人×0.45 + (1−精力)×0.1
```

权重归一到 1，避免单值中等就叠到顶。

### 2｜岸 · 好感层（天～周）

慢变量，按人记账：

- 全局好感：决定主不主动
- 对人的 warmth：长期印象
- 对人的 resentment：芥蒂，带半衰期，不牵连别人

### 3｜海底 · 记忆层（周～月）

事实账本，只记录、不表态：

- 情景记忆：第一人称、带情绪、强度随时间衰减
- 召回：关键词 + 向量 + 在场的人 + 当前心情
- 敏感记忆：私密版 + 去名字/细节的公开版，跨场景只召回公开版

### 4｜航道 · 名单层（离散承诺）

- 进入/退出都要滞后，不能一句话触发
- 只读长期好感，不读当下情绪
- 每一次变动都应能解释

## 数据流

```
记忆（事实） ──喂──> 好感（长期评价）
     │                  │
     └──> 情绪（当下状态）<── 身体 / 事件 / 刚想起的旧事
                        │
                        └──> 说话方式 / 接话概率 / 主动频率
好感 + 名单（策略） ──> 能不能找、找谁、多久找一次
```

## 设计原则

1. 快变量可以影响说话，但不该直接改慢变量和规则。
2. 名单不跟当下情绪走；拉黑/放出都要滞后、能解释。
3. 一个人惹的事，不牵连所有人。
4. 记忆只记录，不直接下判断。
5. 人格是常量：情绪可以变，风格和底线不变。

## 最小接入（伪代码）

```js
onMessage(msg):
  decayState()                       // 时间流逝
  mood = deriveMood(state)           // 三个行为出口
  memory = recall(msg, key, mood)    // 关键词 + 向量 + 在场的人
  prompt = persona + moodBlock + memory + history
  reply = llm(prompt)
  applyStateDeltas(reply.tags)       // <state .../>
  saveMemory(reply.tags)             // <remember .../>
  policy = gate(person, state)       // 名单 / 额度 / 冷却
  if policy.allowed: send(reply)
```

只需要三样东西：一个状态文件、一个记忆存储、一个消息入口。LLM 和聊天通道都可以换。
